# WALLSPACE

Браузерная доска для мыши, сенсорного экрана и рук в Meta Quest. На одном устройстве оба режима открывают один рисунок.

## Meta Quest

1. Открой [WALLSPACE](https://vanyaby.github.io/wallspace/) в браузере Quest.
2. Включи отслеживание рук, отложи контроллеры и нажми **Войти в MR**.
3. Коснись верхнего левого угла указательным пальцем и подержи его у стены. Другой рукой наведи на кнопку **Записать точку** и сделай щипок. Разожми пальцы и так же запиши верхний правый и нижний левый углы.
4. Отведи руку от стены после третьей точки. Затем веди указательным пальцем у плоскости. Щипок на кнопке над доской выбирает инструмент. Кнопка **Углы** запускает калибровку заново, а **Выход** возвращает на страницу.

Рисунок сохраняется в хранилище браузера. PNG можно скачать со страницы. Положение доски действует до конца сеанса MR. Импорт PDF, фотографий и задач запланирован отдельно.

## Разработка

Статические файлы без сборки. Запусти любой локальный HTTP-сервер в корне проекта для работы с доской на ПК. Для входа в MR на гарнитуре открой сайт по HTTPS.

Тесты геометрии запускаются командой `node --test tests/geometry.test.mjs`. Симуляция рук в настольном браузере проверяет обработку поз и жестов. Точность физического касания и passthrough требуют теста на гарнитуре.
